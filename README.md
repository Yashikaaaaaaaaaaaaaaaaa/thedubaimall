## ✨ Overview

This project is a **video-first, browser-based sales deck** built to replace fragmented, static presentations used in large-scale retail properties.

Instead of switching between PDFs, videos, and spreadsheets, this experience delivers a **single, immersive narrative** that communicates:

- Scale  
- Energy  
- Commercial opportunity  

It is designed for:
- Retail tenants  
- Brand partners  
- Event organizers  

> The goal is simple:  
> **Make the viewer feel — “We need to be here.”**

---

## 🎯 Core Experience

The deck is structured as a **non-linear, scroll-driven journey**, where each section serves a clear business purpose:

- 🎬 **Hero** — Instant emotional impact through cinematic video  
- 🌍 **Why This Property** — Scale, location, and global reach  
- 🛍️ **Retail Ecosystem** — Brand credibility and positioning  
- 💎 **Luxury Experience** — Premium audience and environment  
- 🍽️ **Dining & Lifestyle** — Engagement and dwell time  
- 🎢 **Attractions** — Core traffic drivers (the moat)  
- 🎤 **Events & Platform** — Conversion into partnerships and bookings  

Every section is designed to **move the user closer to action**.

---

## 🧠 Design Thinking

This is not a traditional website.

It is a **sales tool disguised as an experience**.

Key principles:

- **Video-first storytelling**  
  Content is shown, not explained  

- **Minimal UI, maximum focus**  
  Inspired by Apple, Tesla, luxury brands  

- **Cinematic pacing**  
  Fast → slow → fast to control attention  

- **Non-linear navigation**  
  Users explore based on interest  

- **Conversion-driven design**  
  Every section leads to leasing, partnerships, or events

## ⚙️ Tech Stack

- **TypeScript** — Primary development language  
- **React** — Component-based architecture  
- **Tailwind CSS** — Utility-first styling system  
- **GSAP** — Scroll-based animations and transitions  

---

## 🚀 Performance Considerations

- Lazy-loaded media assets  
- Optimized video usage (short loops, compressed formats)  
- Minimal DOM complexity  
- Smooth scroll performance (no jank)  

Target: **90+ Lighthouse score**

---

## 🤖 AI Usage

AI was used strategically to accelerate development:

- Generating cinematic visuals where assets were unavailable  
- Assisting in copywriting and narrative refinement  
- Rapid ideation of UI/UX patterns  

The focus was on **enhancing quality and speed**, not replacing thinking.
